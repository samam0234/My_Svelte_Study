# public

Vite가 번들에 넣지 않고 주소 그대로 제공하는 정적 파일입니다.

- 저장소 전체: [README.md](../../../README.md)
- 상위 폴더: [README.md](../README.md)

## 목적

빌드가 가공하면 안 되는 파일을 둡니다. 개발 서버와 `dist/` 모두에서 사이트 루트 경로로 열립니다.

## 파일

| 파일 | 기능 |
|---|---|
| `favicon.svg` | 브라우저 탭 아이콘. `index.html`이 `/favicon.svg`로 연결 |

이미지를 추가하면 이 폴더에 두고 `/파일명`으로 참조하면 됩니다.
